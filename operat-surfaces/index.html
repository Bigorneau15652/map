Configuration des tables sources

Le widget a besoin de savoir quelle table de votre document contient la nomenclature OPERAT (catégorie / sous-catégorie / code technique). Il essaie d'abord Segmentation_OPERAT automatiquement ; si votre table porte un autre nom, ou si les menus déroulants « Catégorie OPERAT » / « Sous-catégorie OPERAT » de l'écran de paramétrage restent vides, choisissez la bonne table ci-dessous.

Notice explicative

1. Choisir un EFA (site) puis, si besoin, un bâtiment. Le menu EFA (site) limite l'affichage aux 5 sites encore en activité. Le menu Bâtiment permet de voir le détail d'un seul bâtiment, ou de rester sur « Tous les bâtiments (agrégé) » pour le total de l'EFA.

2. Lire les résultats. Le tableau « Surfaces par catégorie OPERAT » liste, pour chaque sous-catégorie OPERAT, une ligne par statut thermique (chauffée seule, chauffée + rafraîchie, rafraîchie seule, non chauffée/non rafraîchie). Le tableau « Hors périmètre » liste séparément les locaux sans usage occupé propre (combles, trémies, logements de fonction…), non comptés dans les totaux OPERAT.

3. Paramétrer les correspondances (bouton ⚙). Nécessite d'avoir choisi un bâtiment précis (pas « Tous les bâtiments »). Pour chaque type de local présent dans ce bâtiment, choisissez un Mode :

  • Affectation directe — le local pointe vers une sous-catégorie OPERAT précise. Les menus Catégorie OPERAT et Sous-catégorie OPERAT ne sont actifs que dans ce mode — s'ils sont grisés, changez d'abord le Mode sur « Affectation directe ».
  • Répartition au prorata — pour les circulations, sanitaires, locaux techniques… sans équivalent OPERAT propre. Réparti automatiquement, ajustable dans la section suivante.
  • Hors périmètre — exclu de la déclaration (combles, trémies, logements de fonction…).

4. Répartition manuelle du prorata. Exemple : une circulation de 118 m² à répartir, 33 % vers Bureau et 67 % vers Salles de classe → entrez 33 dans la case % en face de « Bureau » ; le tableau affiche aussitôt les m² correspondants (≈ 38,9 m² pour 33 %, le reste se répartissant automatiquement). Laissez le % vide pour revenir à l'automatique sur cette ligne.

5. Case « Afficher le code technique OPERAT ». Ajoute le code SCAP… à côté de chaque sous-catégorie dans les résultats — pratique pour la déclaration, pas toujours obligatoire au quotidien.

6. Fenêtre flottante (bouton ⛶ en haut à gauche). Ouvre les résultats actuels dans une fenêtre de navigateur séparée, que vous pouvez déplacer sur un second écran. Cette fenêtre se met à jour automatiquement à chaque changement d'EFA/bâtiment/case à cocher tant qu'elle reste ouverte — pas besoin de la rouvrir.
